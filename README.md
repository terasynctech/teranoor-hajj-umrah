# TeraNoor Hajj & Umrah

GitHub Pages-ready single-page website for **TeraNoor Hajj & Umrah — An Initiative of TeraSyncTech**.

## Files
- `index.html` — complete homepage
- `css/style.css` — responsive design
- `js/script.js` — mobile menu + WhatsApp enquiry form
- `assets/` — place your own logo/photos here

## Publish on GitHub Pages
1. Create a new GitHub repository, for example `teranoor-hajj-umrah`.
2. Upload `index.html`, the `css` folder, `js` folder and `assets` folder.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch** → `main` → `/root`.
5. Save. GitHub will provide the live Pages URL.

## Before launch
- Replace the temporary email `info@teranoor.com` with your real email.
- Replace/add your final office address.
- Replace remote demo image URLs with your own licensed images if desired.
- Add your final package prices only after confirming hotel, transport, flight, visa and other inclusions.
- Add any Hajj/Umrah authorization or accreditation statements only after the relevant approvals are in place.
