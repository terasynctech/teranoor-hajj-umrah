TeraNoor Hajj & Umrah – GitHub Pages

This package contains the single-file TeraNoor website so CSS/JS do not depend on a separate stylesheet.

IMPORTANT IMAGE NOTE
The website package is prepared and GitHub-ready, but the verified Wikimedia image binaries could not be bundled in this environment because outbound image downloads are unavailable. The existing HTML therefore still contains its original remote image URLs.
